# MKDIR-Digital

Geschäftliche Website für Webdesign, Grafik, Social Media und Online-VCards.

## Lokal starten

```bash
npm ci
npm run dev
```

## Qualität prüfen

```bash
npm run lint
npm run build
```

Die Veröffentlichung erfolgt automatisch über den eigenen GitHub-Actions-Workflow nach jedem Push auf `main`.
